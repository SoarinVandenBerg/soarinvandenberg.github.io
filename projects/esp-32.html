ESP-32 Project



This is where ill put all the info for my ESP-32 project. I don't think anyone will read this, but im just going to use this as a spot to keep all the info so I don't lose it.

This project consists of ~25 games, a bunch of basic apps, and some other useful stuff. It has the same theme as this website, and it's got a bunch of other features such as a stats logger, settings page, multiplayer and singleplayer on most games, and some other stuff. I originally made the globe pixel art animation for the idle screen for the device, but am just using the freeze frame, but theres an option to revert in settings.

Before even considering doing this, read all of the instructions below.


What you need:


-An ESP-32
-The base code
-A 3.7V Lithium battery
-Thronny
-A USB-C transfer cable


Once you have all of the materials set up, follow these steps to make it look like the one I've been working on. To help, there's an file on the github repository with more detailed instrustions on how to flash it, and load files. Contact me if you need any help setting it up.


Step 1: Install the battery. It should be pretty easy, as it's just connecting the cables, and unscrewing the bottom.

Step 2: Turn it on by holding the button on the bottom for ~10s, and the base software that comes with it should be there. Turn it off once you make sure it works, and you dont need to return it.

Step 3: Factory reset the ESP-32. You'll need the cable I talked about earlier for this step. I dont really remember how to do this part, as it's been a while. There's lots of good tutorials on youtube, just look up "resetting ESP-32 to factory" or "wiping an ESP-32".

Step 4: Install my software (or make your own!!). To port it onto the device, install and setup Thronny, the download link is above. It's pretty intuitive but make sure to watch some videos on the topic as it is possible to brick the device. It doesnt take that long to transfer over the files, but it is pretty slow. For the first time with all of them it should be like 20mins but no more. If it's more than an hour use another port in your computer or a different cable.

Step 5: Set up the date, time, etc. It's all in the device's settings so it should be pretty intuitive. It has an internal clock so it'll keep time even when it's off.

Step 6: Set up a Micro-SD card. This is useful if you want to store books, pictures, or any type of text file on the device. To set this up, first create 3 folders called "Books", and "Pics". The books need to be .txt files, and the pictures can have multiple folders inside of the main folder if you want. Only one layer deep though. The only available type of image you can do is .jpg, i'm not sure what happens if you test this and it doesnt work, but its not worth trying. To convert your images to .jpg's use the link on the "pages" part of my site.


Some more tricks/shortcuts:



Thronny shortcuts:
-CTRL+D: Use when plugging the ESP-32 into your computer and boot it up.
-CTRL+C: Reboots the device. Use sparingly, CTRL+D is more useful.

General UI info:
-Holding the bottom button for ~10s turns the device on.
-Holding both side buttons at the same time until the screen flashes with green lines turns it off.
-To exit to the homepage, click the top button, and then press the screen when the globe appears.
-If you ever run into any problems/if it crashes, just restart it and it should be fixed.

Known Bugs (ill get around to fixing these eventually):
-Winning a wordsearch completely crashes it, with the only way to fix is restarting.
-The wordle app's scoring is broken, but still playable.
-Some display elements get cut off by the rounded corners of the display.
-There is no way to reset the stats without going to the text files.
-Geometry dash is not even close to being done and is impossible to win.
-The medium and hard checkers bots are literally impossible to beat.
-Touch sensitivity only works one spot at a time, which is annoying for mulitplayer games.
-The ball version of the drawing program gets glitchy quickly whjen the number if balls goes up.

Secret passwords in the calculator app:
-54321: Enables drive mode, which toggles the notes, books, and photos apps.
-3.14159: Shows the time stats of each app.
-[IDK]: Hides all games that arent "educational".
-[IDK]: Toggles the lazer app (if installed)
-If you get a perfect score against the highest level AI in pong, it takes you to "Impossible Mode", where the ball speeds up 2x the normal amount, and only your paddle shrinks. I've only beat this once with a lot of luck, so have fun!
