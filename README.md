# Soarin's Website!
This website is a project of mine, and the original goal of it was to get better at coding! I started working on it in march of this year, and have been updating it ever since. It has grown to a total of 31 pages.

## How I made the site
I coded it in javascript, and the pages are in html. I've also coded all of this by hand, without the use of AI! I tried to give it a very hacker-y vibe with the green, white and black but idk if that worked out good.
