## How to run it locally

For the absolute BEST experience (and to make sure that all the navigation links work properly), visit the live site at [soarinvandenberg.ca](https://soarinvandenberg.ca).

If you need to run it locally, follow these steps:

1. Clone the repository:
```sh
git clone https://github.com/SoarinVandenBerg/soarinvandenberg.github.io.git
```
2. Navigate to the folder
```sh
cd soarinvandenberg.github.io
```

3. Start a local server. If you have python installed use:
```sh
python -m http.server 8000
```

4. Open your browser and go to [http://localhost:8000](http://localhost:8000)
(Becuase this site relies on Github Pages, Python's local server doesnt recognize filenames. If you want to test the routing locally, you will need to manually type .html at the end of the URL in your browser.)
